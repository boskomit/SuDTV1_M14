# User Stories

Status: team-provided baseline; English editorial normalization.

| ID | As a viewer, I want to... | Acceptance criteria |
|---|---|---|
| US-01 | Select a TV service using next/previous navigation, direct channel number entry, or the service list. | Each selection method starts live playback of the selected service and displays its information. |
| US-02 | Open the TV Guide and see what is being broadcast. | The TV Guide displays the schedule of the selected service using data obtained from the OTT MW server. |
| US-03 | Control audio and operate the application using a keyboard. | Volume and mute controls affect the active A/V session, and application controls are accessible without a mouse. |
| US-04 | Rewind the currently viewed content by 30 seconds, repeatedly if desired. | Each confirmed rewind operation uses the current playback position as its reference. |
| US-05 | Select playback quality independently of rewind operations. | Once playback of the selected variant actually begins, the active quality and displayed quality indicator correspond to that variant. |
| US-06 | See how far behind live playback I am and return to the live programme. | A single time-related value is displayed. The Go Live command starts playback of the current live content of the same service. |
| US-07 | Understand playback errors and continue watching. | An error message explains the problem. Following a failed rewind operation, the Go Live action remains available. |
